# Поддержка шаблона

Пользовательский путь — README и файлы chatgpt. Команды ниже нужны только сопровождающему или агенту с доступом к Python.

## Источники и сборка

- `00_PROJECT_INSTRUCTIONS.txt` — компактные инструкции проекта.
- `01_ONBOARDING.txt` — диалог, профиль и практикум.
- `02_RESEARCH.txt` — методика и персонализация.
- `03_DELIVERABLES.txt` — структура и качество результатов.
- `04_EXPORTER.txt` — автоматически собранный контракт данных и код `scripts/export_report.py`; вручную не редактировать.

```sh
python3 -m pip install -r requirements-dev.txt
python3 scripts/build_chatgpt_pack.py
python3 -m unittest discover -s tests
python3 scripts/build_chatgpt_pack.py --check
```

Сборщик берёт только явно перечисленные файлы, не рекурсивно всю рабочую папку. Выход — `dist/Alpes-ChatGPT-Starter.zip`. В нём инструкция старта, инструкции проекта, четыре файла знаний и лицензии. В архив не входят профили, исследования, история Git и окружение.

При изменении кода сначала пересоберите `04_EXPORTER.txt`. Проверяйте `git diff --cached` перед публикацией; .gitignore не удаляет уже закоммиченные данные. Для реальных профилей используйте ignored-папку `private/`; не добавляйте её с `git add -f`.

## Экспорт

```sh
python3 scripts/export_report.py examples/demo_report.json private/demo-v1
```

Экспортёр принимает подготовленный JSON, проверяет структуру/ссылки между утверждениями и источниками, создаёт ровно три файла. Он не ищет сведения, не проверяет правдивость текста и не открывает внешние ссылки. Существующую папку результата не перезаписывает. Для следующей версии используйте новую папку; пользователю отдавайте только актуальную.

Формат JSON показан в `examples/demo_report.json` и в `04_EXPORTER.txt`. Для каждого факта нужен источник, для гипотезы — альтернатива и вопрос. Дата — YYYY-MM-DD; источники — S01…S999. Ссылки — HTTP(S) без учётных данных, для вложений вместо URL задайте locator.

PDF использует встроенный PT Sans; в среде ChatGPT возможен системный DejaVu Sans/Noto Sans. Путь к иному TTF передаётся через `--font`. Word использует Arial и редактируемые абзацы. PDF и Word строятся из единого потока содержания. Экспортёр намеренно минимален: финансовые сравнения в нём оформляются текстом; нативные таблицы можно создать средствами документов ChatGPT по правилам 03_DELIVERABLES.

## Проверка выпуска

1. Проверить инструкции на отсутствие предположений о продукте/компании конкретного пользователя.
2. Пройти сценарии из CONVERSATION_TESTS.md. Это ручные критерии поведения модели, не доказательство прохождения тестов одним наличием файла.
3. Запустить структурные тесты и генерацию синтетического примера.
4. Открыть PDF и Word, проверить все страницы, кириллицу, ссылки, отсутствие обрезания и одинаковые данные. Открыть SOURCES.txt.
5. Просмотреть состав архива, проверить наличие только разрешённых файлов.
6. Публиковать только шаблон. Не менять видимость GitHub-репозитория без поручения владельца.

Выпуск в приватном репозитории доступен только пользователям с доступом. Для передачи без доступа можно отправить чистый ZIP самостоятельно. Не обещайте доступ «любому по ссылке», пока репозиторий приватный.

## Обновление проекта пользователя

Скачайте свежий комплект, замените инструкции проекта и четыре файла знаний. Сохраните личный профиль отдельно. Не загружайте дубликаты версий под одинаковыми именами. Напишите в чате «Используй новую версию методики; мой согласованный профиль остаётся прежним». GitHub и ChatGPT автоматически не синхронизируются.
