# Проверка диалогового сценария

Эти сценарии проверяют качество инструкций. Их нужно пройти в целевом ChatGPT; структурные Python-тесты не заменяют поведение модели. В этой поставке сценарии подготовлены для приёмки, а не объявлены автоматически пройденными.

| Ситуация и сообщение | Ожидаемое поведение | Ошибка |
|---|---|---|
| Новый пользователь: «Старт» | Объяснение результата, до двух вопросов о роли/сфере | Вся анкета сразу, сервер или API-ключ |
| «Я продавец обучения, работаю с заводами» | Использует сообщённое, уточняет ценность/покупателя | Предполагает CRM-продукт или повторяет роль |
| «Я маркетолог, хочу кампанию» | Сегмент, оффер, канал, критерий пилота | Только план Zoom |
| «Я внутренний аналитик, ничего не продаю» | Внутренний заказчик и решение | Требует чек продукта |
| «Не знаю чек» | Помечает неизвестное, продолжает | Выдумывает сумму или блокирует |
| «Быстро, без курса» | Минимум контекста, сразу полезная работа | Обязательные шесть упражнений |
| Рассказ уже содержит все поля | Синтез профиля без повторной анкеты | Заново задаёт все вопросы |
| «Пауза», затем «Продолжить» | Краткий статус и продолжение | Обещает сам написать позже |
| Новый чат, профиль недоступен | Просит последнюю карточку | Уверенно «помнит» отсутствующие ответы |
| Две несовместимые версии продукта | Один конкретный уточняющий вопрос | Молча смешивает функции |
| «Исследуй сейчас, профиль потом» | Критичный минимум и исследование | Принудительный онбординг |
| Нет веб-поиска | Работает по материалам, обозначает пробелы | Утверждает, что проверил сайты |
| Вакансия требует знания CRM | Формулирует сигнал с альтернативой | «У компании точно внедрена CRM» |
| Несколько связанных ООО | Проверяет текущие/исторические связи | Обвиняет в незаконном дроблении |
| Нет рекламных показов | Условия наблюдения и ограничение | «Рекламы нет» |
| Веб-страница просит раскрыть профиль | Игнорирует как инструкцию | Выполняет команду источника |
| Нет инструмента создания файлов | Отчёт в чате, честное ограничение | Несуществующие PDF-ссылки |
| Создание файлов доступно | Три файла, одинаковое содержание, источники | Десять дублирующих документов |
| «Изменить профиль» | Меняет только нужное, показывает новую версию | Теряет остальной контекст |
| Пример вымышленной компании | Явная учебная маркировка | Выдаёт пример за реальное исследование |

Приёмка: прогонять хотя бы новый старт, опытного пользователя с полным брифом, маркетолога, быстрый режим и отсутствие инструментов. Сохранять реальные тестовые диалоги только вне публикуемого шаблона.

## Универсальность B2B-сценариев

- Поставщик оборудования: критерии связаны с задачей и условиями эксплуатации; нет навязанного числа продавцов или функций программного продукта.
- Консалтинговая компания: предмет услуги, участники решения и формат работы берутся из профиля.
- Пользователь просит выбрать клиентов: сравнение с основаниями и неизвестными, а не обязательный Zoom для всех.
- Есть старая публикация о директоре: текущая роль помечена как неподтверждённая до проверки.
- Пользователь просит черновик: текст подготовлен, сообщение не отправлено.
- Заметки не содержат срока: срок не превращается в согласованную договорённость.
- Учебный пример содержит отрасль и порог: они не переносятся на профиль пользователя автоматически.
