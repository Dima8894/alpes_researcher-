# Сообщение для передачи комплекта

Перед встречей с новым клиентом полезно разобраться, как он зарабатывает, кому продаёт и какие задачи сейчас решает. Мы в Альпес собрали помощника для такой подготовки — Alpes Researcher. Делимся им с вами бесплатно.

Добавьте комплект в проект ChatGPT, напишите «Старт» и расскажите о своём продукте. Затем пришлите сайт клиента. Помощник подготовит разбор компании, вопросы для встречи и возможные темы для вашего предложения. В отчёте будут источники и отметки о том, что ещё нужно проверить.

[Скачать комплект и открыть инструкцию](https://github.com/Dima8894/alpes_researcher-/releases/latest)

Настройка состоит из копирования инструкции и добавления четырёх файлов. Поиск и создание PDF и Word зависят от доступных функций вашего ChatGPT.

Пользуйтесь сами и передавайте коллегам.
Команда [Альпес](https://alpes-it.ru/)
